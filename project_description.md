# Ride Hub

Ride Hub is a project for comparing ride services such as Uber, Ola and Rapido.

## Member 3 – Data Cleaning

Member 3 worked on collecting, cleaning and checking the ride review dataset.

## Data Cleaning Steps

- Checked for missing values
- Removed duplicate records
- Checked data types
- Verified rating and price values
- Checked the final dataset structure

## Final Dataset

The cleaned dataset contains 19,824 records.

### Columns

- App
- Review
- Rating
- Date
- Price (₹)
